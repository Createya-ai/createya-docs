# O3 pro

> O3 pro

**Стоимость:** 21 кредитов / запрос (21кр/input_video_duration_seconds · 1–15 input_video_duration_seconds).

**Family slug:** `kling` · **Output:** video · **Mode:** sync



## Быстрый старт

### curl

```bash
curl -X POST https://api.createya.ai/v1/run \
  -H "Authorization: Bearer $CREATEYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-video-o3-pro-v2v",
    "input": {
      "prompt": "your prompt"
    }
  }'
```

### Python

```python
import os, requests
KEY = os.environ["CREATEYA_API_KEY"]
r = requests.post(
    "https://api.createya.ai/v1/run",
    headers={"Authorization": f"Bearer {KEY}"},
    json={"model": "kling-video-o3-pro-v2v", "input": {"prompt": "your prompt"}}
)
print(r.json())
```

### Node.js

```javascript
const r = await fetch("https://api.createya.ai/v1/run", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.CREATEYA_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "kling-video-o3-pro-v2v",
    input: { prompt: "your prompt" }
  })
});
console.log(await r.json());
```

## Параметры

| Параметр | Тип | Required | Описание |
|---|---|---|---|
| `prompt` | string | ✓ | Текстовое описание желаемого результата. Обязательный параметр. |
| `elements` | file_array |  | Элементы (персонажи/объекты) для включения. Указывайте их в промпте как @Element1, @Element2. |
| `keep_audio` | boolean |  | Сохранять ли оригинальную аудиодорожку из исходного видео. |
| `shot_type` | string |  | Тип генерации видео с несколькими планами. |

# 2

> Faster. Sharper. Smarter.

**Стоимость:** 5 кредитов / запрос (resolution: 1K=5кр, 2K=8кр, 4K=12кр).

**Family slug:** `nano` · **Output:** image · **Mode:** sync

📚 [Полный обзор модели на createya.ai](https://createya.ai/knowledge/nano-banana-2)

## Быстрый старт

### curl

```bash
curl -X POST https://api.createya.ai/v1/run \
  -H "Authorization: Bearer $CREATEYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nano-banana-2",
    "input": {
      "prompt": "your prompt"
    }
  }'
```

### Python

```python
import os, requests
KEY = os.environ["CREATEYA_API_KEY"]
r = requests.post(
    "https://api.createya.ai/v1/run",
    headers={"Authorization": f"Bearer {KEY}"},
    json={"model": "nano-banana-2", "input": {"prompt": "your prompt"}}
)
print(r.json())
```

### Node.js

```javascript
const r = await fetch("https://api.createya.ai/v1/run", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.CREATEYA_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "nano-banana-2",
    input: { prompt: "your prompt" }
  })
});
console.log(await r.json());
```

## Параметры

| Параметр | Тип | Required | Описание |
|---|---|---|---|
| `prompt` | string | ✓ | Текстовое описание желаемого результата. Обязательный параметр. |
| `aspect_ratio` | enum |  | Соотношение сторон изображения. Auto — автоматически. |
| `resolution` | enum |  | Разрешение изображения. 1K — быстрее и дешевле, 4K — высокое качество. |
| `output_format` | enum |  | Формат выходного изображения. |

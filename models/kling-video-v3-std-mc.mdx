# V3 pro

> V3 pro

**Стоимость:** 16 кредитов / запрос (16кр/input_video_duration_seconds · 1–15 input_video_duration_seconds).

**Family slug:** `kling` · **Output:** video · **Mode:** sync



## Быстрый старт

### curl

```bash
curl -X POST https://api.createya.ai/v1/run \
  -H "Authorization: Bearer $CREATEYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kling-video-v3-std-mc",
    "input": {
      "prompt": "your prompt"
    }
  }'
```

### Python

```python
import os, requests
KEY = os.environ["CREATEYA_API_KEY"]
r = requests.post(
    "https://api.createya.ai/v1/run",
    headers={"Authorization": f"Bearer {KEY}"},
    json={"model": "kling-video-v3-std-mc", "input": {"prompt": "your prompt"}}
)
print(r.json())
```

### Node.js

```javascript
const r = await fetch("https://api.createya.ai/v1/run", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.CREATEYA_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "kling-video-v3-std-mc",
    input: { prompt: "your prompt" }
  })
});
console.log(await r.json());
```

## Параметры

| Параметр | Тип | Required | Описание |
|---|---|---|---|
| `prompt` | string | ✓ | Текстовое описание желаемого результата. Обязательный параметр. |
| `character_orientation` | enum | ✓ | Определяет, соответствует ли ориентация персонажа в результате исходному изображению или видео. «video»: ориентация соответствует исходному видео — лучше для сложных движений (макс. 30s). «image»: ориентация соответствует исходному изображению — лучше для следования за движениями камеры (макс. 10s). |
| `keep_original_sound` | boolean |  | Нужно ли сохранять оригинальную звуковую дорожку из исходного видео. |

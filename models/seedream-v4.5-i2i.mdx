# V4.5

> V4.5

**Стоимость:** 5 кредитов / запрос (× num_images (1–6)).

**Family slug:** `seedream` · **Output:** image · **Mode:** sync



## Быстрый старт

### curl

```bash
curl -X POST https://api.createya.ai/v1/run \
  -H "Authorization: Bearer $CREATEYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedream-v4.5-i2i",
    "input": {
      "prompt": "your prompt"
    }
  }'
```

### Python

```python
import os, requests
KEY = os.environ["CREATEYA_API_KEY"]
r = requests.post(
    "https://api.createya.ai/v1/run",
    headers={"Authorization": f"Bearer {KEY}"},
    json={"model": "seedream-v4.5-i2i", "input": {"prompt": "your prompt"}}
)
print(r.json())
```

### Node.js

```javascript
const r = await fetch("https://api.createya.ai/v1/run", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.CREATEYA_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "seedream-v4.5-i2i",
    input: { prompt: "your prompt" }
  })
});
console.log(await r.json());
```

## Параметры

| Параметр | Тип | Required | Описание |
|---|---|---|---|
| `prompt` | string | ✓ | Текстовое описание желаемого результата. Обязательный параметр. |
| `num_images` | integer |  | Количество отдельных запусков генерации модели для данного промпта. |
| `image_size` | enum |  | Размер генерируемого изображения. Ширина и высота должны быть от 1920 до 4096, либо общее количество пикселей должно быть в диапазоне от 2560*1440 до 4096*4096. |
| `width` | integer |  | Ширина изображения в пикселях |
| `height` | integer |  | Высота изображения в пикселях |
| `max_images` | integer |  | Если установлено значение больше единицы, включается генерация нескольких изображений. Модель может возвращать до `max_images` изображений за каждую генерацию, и всего будет выполнено `num_images` генераций. Общее количество созданных изображений составит от `num_images` до `max_images*num_images`. Общее количество изображений (входящих + исходящих) не должно превышать 15. |
| `enable_safety_checker` | boolean |  | Если выбрано значение true, будет включен фильтр безопасности. |
| `seed` | integer |  | Случайное число (seed) для контроля стохастичности генерации изображений. |

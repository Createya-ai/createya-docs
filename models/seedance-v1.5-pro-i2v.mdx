# 1.5 Pro

> 1.5 Pro

**Стоимость:** 20 кредитов / запрос (resolution: 480p=9кр, 720p=20кр, 1080p=45кр; 4кр/сек · 4–12 сек).

**Family slug:** `seedance` · **Output:** video · **Mode:** sync



## Быстрый старт

### curl

```bash
curl -X POST https://api.createya.ai/v1/run \
  -H "Authorization: Bearer $CREATEYA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-v1.5-pro-i2v",
    "input": {
      "prompt": "your prompt"
    }
  }'
```

### Python

```python
import os, requests
KEY = os.environ["CREATEYA_API_KEY"]
r = requests.post(
    "https://api.createya.ai/v1/run",
    headers={"Authorization": f"Bearer {KEY}"},
    json={"model": "seedance-v1.5-pro-i2v", "input": {"prompt": "your prompt"}}
)
print(r.json())
```

### Node.js

```javascript
const r = await fetch("https://api.createya.ai/v1/run", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.CREATEYA_API_KEY}`,
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "seedance-v1.5-pro-i2v",
    input: { prompt: "your prompt" }
  })
});
console.log(await r.json());
```

## Параметры

| Параметр | Тип | Required | Описание |
|---|---|---|---|
| `prompt` | string | ✓ | Текстовое описание желаемого результата. Обязательный параметр. |
| `aspect_ratio` | enum |  | Соотношение сторон сгенерированного изображения/видео |
| `duration` | enum |  | Длительность видео в секундах |
| `generate_audio` | boolean |  | Генерировать аудио для видео |
| `resolution` | enum |  | Разрешение генерации |
| `enable_safety_checker` | boolean |  | Включить фильтр безопасности контента |
| `camera_fixed` | boolean |  | Зафиксировать положение камеры |
| `seed` | integer |  | Сид для генератора случайных чисел. Одинаковый сид даёт одинаковый результат. |
